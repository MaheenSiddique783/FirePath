# Project Charter

**Project Name:** FirePath
**Date Produced:** October 2026

## Project Goals
To build a Canadian wildfire behaviour map application that empowers the general public (cabin owners, farmers, campers) to easily visualize fire risks using official Canadian fire science and free government data. This supports the goal of increasing public safety and accessibility to critical environmental data.

## Project Objectives
- Deliver a mobile-based map app (MVP 1) focused on Saskatchewan by December 2026.
- Create an automated daily data pipeline to pull from Canadian government sources (e.g., CWFIS, Natural Resources Canada).
- Run Canadian fire equations to calculate spread speed, intensity, and output 1, 2, and 4-hour spread shapes.
- Translate technical danger ratings into plain-language explanations for the public.

## Project Budget
$0 (Student Capstone Project). All data sources used are free or require a free API key.

## Project Sponsor
N/A



## Additional Key Project Stakeholders
- End-users (Cabin owners, farmers/ranchers, rural municipalities, campers)

## Overall Project Milestones
- **October 2026:** User interviews, data source testing, UI/UX prototyping.
- **November 2026:** Data pipeline active, accuracy tests passed, hi-fi prototype complete, Bazaar day demo.
- **December 2026:** MVP 1 completed.

## Overall Project Risks
- **Data availability:** Reliance on external government APIs that may experience downtime or require data cleaning.
- **Technical accuracy:** Ensuring the fire equations match FBP Go and REDapp outputs exactly.
- **User misinterpretation:** The risk of users treating the app as a guaranteed safety forecast rather than a scenario/guide.
